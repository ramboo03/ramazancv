# RamazanOS

Interactief 3D-portfolio van Ramazan, student HBO-ICT Software Engineering aan Windesheim Almere.

Je komt binnen in een 3D-kamer met een bureau. Klik op de laptop en de camera vliegt het scherm in, waar het cv draait als een eigen besturingssysteem: elk onderdeel (over mij, opleiding, skills, projecten, ervaring, contact) is een app met versleepbare vensters, en er is een werkende terminal.

## Techniek

- Eén statisch bestand: `index.html`
- 3D met [Three.js](https://threejs.org) r128 via cdnjs
- Lettertypes via Google Fonts (Instrument Serif, Geist, Geist Mono)
- Geen build-stap en geen dependencies om te installeren

## Lokaal bekijken

Open `index.html` in een browser, of start een simpele server:

```bash
npx serve .
```

## Online

De site draait via GitHub Pages vanaf de `main`-branch.
